# 网点渐变技术规范 / Texture Spec

这份文件是整套风格能不能被认出来的关键。

## 核心原则:两种纹理工具,对应两种相反的物理过程

这套系统有**两种**纹理语言，不是只有网点。用哪一种，取决于这段渐变代表的是"变少/变疏/往外走"还是"变多/变重/往深处走"：

### 网点（halftone dot）——表现"消散"

用于任何**从聚集走向稀疏、从实体走向消失**的现象：雾、光晕扩散、烟的飘散、裂痕分岔末端、涟漪向外变弱、脚印被抹平。圆形，从实色到密网点到疏网点到无。这是最常用的工具，之前所有规则都是围绕它写的。

### 网纹（crosshatch / 交叉网纹）——表现"深度与密度"

用于任何**从稀薄走向浓重、从表层走向纵深**的现象：深水的压强感、浓重的阴影、厚重材质的体积感——方向和网点相反，不是消散，是加深。交叉线条，从疏到密，越深处越密。这类现象如果用网点表现（比如让深水像雾一样"消散"），逻辑是反的，词不达意。

**判断方法**：这段渐变，东西是在"变少/往外走"，还是在"变多/往里走/往下沉"？前者用网点，后者用网纹。不确定的时候，问自己"这是在扩散，还是在深入"。

### 强制底线：每张图至少要有一处纹理渐变

不管选网点还是网纹，**每张图必须至少有一处使用这套纹理语言**——不能整张图只有纯色块和纸张颗粒噪点，一处渐变都没有。哪怕主体本身是静态陈列、没有天然的扩散或深度动作（比如一把孤立的椅子），也要在阴影、材质细节，或者背景的某个角落，找一个地方安放网点或网纹——这是这套系列视觉辨识度的最后防线。生成后如果发现整张图没有一处纹理渐变，必须回去补一处，哪怕很小。

### 场合 A：网点表现渐变过渡（消散类，替代传统模糊渐变）

任何原本会用"渐变色"表现的消散类现象——色块边缘的消散、光晕、空气透视——**一律用网点疏密变化代替，禁止使用传统的径向/线性模糊渐变**。

规则：
- 网点从"实色"过渡到"稀疏的点"再到"完全消失"，密度变化要连贯
- 过渡方向要有物理逻辑：比如墨迹边缘是向外扩散变稀疏，山体阴影是沿光源方向变稀疏，不能随机撒点
- 点的疏密变化区间：中心/主体附近接近实色（点几乎连成一片），边缘区域点的间距逐渐拉开，最外圈只剩零星几个点然后归于纯 Ground 色

### 场合 B：网点表现材质肌理

云的绒感、纸张的颗粒感、大面积色块内部的质感变化，用网点做细腻的纹理叠加。

规则：
- 材质用途的网点密度可以相对均匀，不需要像场合 A 那样有明确的方向性衰减
- 但同一张图里，材质网点和渐变网点的"点的基础大小"应保持一致，不要出现两种明显不同尺寸的网点混用

### 场合 C：网纹表现深度与密度

深水、浓重阴影、厚重材质的体积感——**从疏到密，越深处越密，方向和网点的"消散"相反**。

规则：
- 网纹是交叉线条（crosshatch），不是圆点，两者不要在同一处混用（不同区域可以分别用网点和网纹，但同一片渐变内部不能网点网纹混着来）
- 疏密变化方向要有物理逻辑：越往深处/越被遮挡/越承重的地方，网纹越密
- 网纹密集到一定程度可以接近实色，但要保留看得出线条方向的痕迹，不要糊成纯色块

## 网点/网纹的形状与基础参数

- 网点形状：圆点。网纹形状：交叉直线。两者不能互相替代，也不要在同一处渐变里混用
- 基础大小：相对画面尺寸要小而密，接近传统丝网印刷/雕版的观感，不能是大颗粒的"波普风"网点，也不能是稀疏粗放的网纹
- 颜色：网点/网纹本身只用 Ink 色或 Mist 色（取决于叠在哪一层上），不单独引入专属颜色
- 叠加纸张颗粒噪点：整体画面可以有一层极轻的做旧纸感噪点，独立于网点/网纹系统，用来统一质感，不要盖过其清晰度

## 主体色块的面积上限（配合构图类型）

| 构图类型 | 主体锚点（含网点/网纹过渡区）总占比上限 |
|---|---|
| 横向地平线型 | 上下分割由地平线位置决定，非留白一侧不做单独限制，但地平线位置建议落在画面 55%-75% 高度区间（不要正好一半，正好一半会显得呆板） |
| 静态陈列型（原"单点留白型"） | 主体占比不超过画面 5%（越小越好，留白是这个类型的全部意义）——**这类构图最容易出现"整张图零纹理渐变"的问题（比如孤立小物件的场景），生成后务必检查阴影/材质里是否安放了至少一处网点或网纹** |
| 扩散消散型（原"有机扩散型"） | 实色核心区域不超过画面 30%，加上网点扩散过渡区总计不超过 45% |
| 密度延伸型（新增） | 主体沿某方向从清晰走向浓重/深邃，用网纹表现，上限比照扩散消散型（45%），因为深度层次同样需要足够空间才能读出来——这类构图的"留白"可以是一片有网纹纹理的深色场，不必是纯 Ground 空白 |

## 常见翻车模式自查

生成完成后对照检查：

1. **"这看起来像普通渐变海报"** → 说明用了模糊渐变代替网点，重新生成，prompt 里加强"halftone dot gradient, NOT smooth gradient, NOT gradient blur"的否定式约束
2. **"网点糊成一片看不清颗粒"** → 网点基础尺寸设太大或密度过高，调小
3. **"画面显得很平，没有远近感"** → 没有用到 Mist 色 + 网点做空气透视层次，只用了 Ground/Ink 两色
4. **"网点分布很随意，没有方向感"** → 违反了场合 A 的方向性衰减规则，需要把过渡方向和光源/扩散逻辑重新绑定
 5. **"小面积点光源/小锚点的颜色跑偏成暖色（金/橙/红）而不是规定的 Ink 色值，且这不是你想要的"** → 如果没打算用专色点缀（见 color-cards.md 的 Accent 规则），必须在 prompt 里显式排除邻近色，例如写"warm cream `#EDE4D0`, NOT gold, NOT amber, NOT orange-tinted"这种否定式锚定。**但如果这个暖色恰好是你想表达的"意义奇点"——窗光、烛光、一朵花这类承担画面核心语义的主体——先检查是否符合 Accent 的硬条件（是意义奇点而非装饰、默认只有一处、面积在静态陈列型上限内）——符合就保留，这不是失控，是专色点缀在生效**
6. **"该不该给小主体做网点消散"——不是一刀切,要分边缘类型**:
   - **扩散性边缘**（雾、裂痕蔓延、脚印被抹平、光晕、水渍）——边界本身就是"正在发生的物理消散过程"，必须用网点消散表现，硬边在这里是错误的
   - **结构性边缘**（窗户、建筑线条、人造几何物体的轮廓）——边界本身就该清晰利落，网点消散反而不合逻辑（相当于让一扇窗户"融化"），保持硬边是正确选择，不需要为了"风格统一"强行软化
   - 判断标准：这个边缘在物理世界里"应该"是清晰的还是模糊的，跟着物理直觉走，不要套死规则

## Prompt 里描述网点时的推荐措辞（可直接抄）

中文：
> 使用半调网点（halftone dot）表现渐变与材质，网点从实色逐渐过渡到稀疏散点直至消失，禁止使用传统模糊渐变；网点为圆形，尺寸细密，接近丝网印刷/riso 版画质感。

English：
> Use halftone dot gradients (not smooth gradient blur) for all tonal transitions and texture. Dots transition from solid, to dense, to sparse, to none — direction tied to the physical logic of the shape (diffusion, shadow, atmospheric depth). Dots are circular, fine, and dense, evoking screen-print / riso print reproduction, not a modern digital gradient.
