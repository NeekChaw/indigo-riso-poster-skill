# 配文排版规范 / Typography Spec

> **本版前提（v2，生图直出版）**：文字由图像生成模型在生成海报时**一次性直接画出**，不做后期叠加。文字正确性（不写错字、不糊笔画）视为已由现代生图模型兜底，不再设"禁止模型画中文"这类防线。本规范只负责四件事：**氛围、风格、协调、情绪**。

## 核心立场：文字是"印"出来的事件，不是"写"上去的内容

直出文字的最大优势是字和画面共享同一物理世界——同样的纸、同样的墨、同样的印刷压力、同一层颗粒。但模型不会自动这么做，**除非你在 prompt 里把文字描述成一次印刷事件，而不是一个字体名称**。

- ❌ 无效描述："思源宋体，12pt，深灰色"——模型对字体名和字号无感
- ✅ 有效描述："像老式打字机色带快没墨时敲出来的，墨色是画面上用过的那种雾蓝，笔画尾部有轻微拖拽感，字的右下角被纸的磨损吃掉一点"

写文字段落时永远回答四个问题：**墨有多重、笔画什么性格、字坐在画面的哪一层、字有多旧**（见下方四变量）。

## 默认立场：每张图都有一句文字

这套系统的海报**默认带一句极简文字**——文字不是加分项，是画面的一部分。仅有的例外是用户明确说"不要文字"。

默认配文时，从三个角色里选一个（每张图最多一个）：

- **落款式**：极小的一句话或几个字，安静地待在留白区，功能接近"作者签名"，不解释画面
- **呼应式**：文字的位置、走向或内容和画面的视觉逻辑发生关系（裂痕图里文字放在裂痕延长线上，像裂痕"说"出来的话）
- **节奏式**：文字本身参与网点消散逻辑——一组逐渐稀疏、逐渐消失的字，跟着画面的消散方向一起"被抹去"（脚印图里字跟着脚印消失）

## 四变量系统（每个变量的值必须写进 prompt）

### 变量一：墨色浓度（字有多"重"）

| 档位 | 描述 | 适用 |
|---|---|---|
| 浓 | 接近 Ink 主色的饱和压印 | 文字承担第二锚点；墨夜留白卡里"黑暗里唯一的发声者" |
| 中 | Mist 灰蓝的标准印刷感 | 默认档位，编辑气质 |
| 淡 | 像印版快没墨，部分笔画断掉、发虚 | 落款首选，"耳语感" |
| 隐 | 字的墨和底色只差半个色阶，凑近才读出 | "此处曾有言说"的痕迹感，配合记忆/遗忘意象 |

**铁律：宁可断墨，不要加粗。** 粗黑体瞬间毁掉留白系统；断墨的字再小都有呼吸。

### 变量二：笔画性格（字有多"急"）

- **印刷体的从容**：衬线感、墨量均匀、基线端正 → 配静态陈列型
- **手写体的体温**：铅笔/钢笔质感，线条微颤，字距不完全均匀 → 配私密、记忆类意象
- **拓印/刀刻的钝感**：笔画边缘有阻力感，转角不圆滑，带飞白 → 配山、石、夜等"硬"意象

避免：圆润无衬线 UI 感（苹方/Inter 那种"App 海报模板"调性）、花体、书法表演性的飞白大字。

### 变量三：字与画面的空间关系（字"坐"在哪一层）——直出独有的武器

后期叠加的字永远浮在画面上，直出可以做到三种真实层级：

- **沉底**：字像先于画面印上去的，画面的网点/墨雾从字上"碾"过去，字的局部被盖住一点 → 雾山、层次类构图的首选
- **同层**：字和主体共享同一片墨层、同一套网点逻辑，字的边缘也有同样的网点消散 → 文字是画面的平等成员
- **浮面**：字最后印，墨色最新，边缘最锐利 → 极少用，最接近"贴上去"的观感，仅当文字必须是"此刻发生的声音"时

### 变量四：时间感（字有多"旧"）

- 刚印好：墨色饱满、边缘锐利
- 放了一阵：墨微微晕开，纸的米白透过墨层
- 档案级旧：字和纸一起老化，共享同一套磨损 → 配合回忆、旧物意象

## 协调手法（两条硬规则）

1. **文字必须共享画面的物理逻辑。** 画面里有一场从左到右的消散，文字就不能端端正正坐在角落——要么顺消散方向排列，要么字的右侧笔画也开始散成点。这层关系必须写进 prompt，只说"文字放右下角"模型不会自己想到。
2. **文字面积与墨量按反比定。** 字越大墨越淡，字越小墨越浓。巨大的淡字是氛围，微小的浓字是耳语——反过来就是海报模板味。

## 情绪的最后一步："破"

最高级的文字情绪来自不完整。直出可以轻松做到这些（逐条写进 prompt 才生效）：

- 一句话的最后一个词没印上，只留下压痕
- 同一行字里有一个字墨特别重，像写字的人在那停了一下
- 字的下缘被纸的撕边或磨损裁掉一点
- 字的某个笔画断在网点消散里，像话说到一半

**克制不是字少，是字"有欲言又止的痕迹"。** 每张图最多用一处"破"，用两处以上就变成做旧滤镜。

## 意象 → 文字气质对位表

| 意象类型 | 文字气质配方 |
|---|---|
| 海、辽阔、清晨（深海藏青卡） | 从容的印刷体，墨中偏浓，字距宽——字也要"辽阔" |
| 雾、山、层次（雾山晨蓝卡） | 沉底关系，墨淡，字局部被雾状网点吃掉——字也在雾里 |
| 深夜、孤独、强反差（墨夜留白卡） | 两极可选：极小极浓（黑暗里唯一发声者）或极小极淡（快被遗忘的话） |
| 扩散消散类（墨迹、声波、涟漪） | 节奏式角色，字顺消散方向排，末字笔画融入网点——字是这次消散的一部分 |
| 记忆、旧物类 | 打字机断墨质感，档案级旧，沉底关系 |

## 颜色纪律（不变）

文字颜色只能用色卡里的角色色值（Ground / Ink / Mist，或已启用的 Accent），不引入任何新色相，包括"文字专用色"。文字是这张印刷品的一道工序，不是外来元素。

## 层级与数量

- 每张图最多两级层级：一句话/几个字 + 最多一行极小的落款。不做标题+副标题+装饰小字的堆叠
- 中文一句话为宜，英文 ≤ 5 个词；文字总视觉权重永远低于主体锚点

## Prompt 写法示例

**落款式（深夜海面，墨夜留白卡）：**

> 画面左下角留白区有一行极小的字"潮水不问归期"，像打字机色带将尽时敲出的印痕，墨色是雾层色（Mist）再淡半阶，最后两个字墨色明显更弱，几乎隐入纸面；字的边缘有和画面一致的纸张颗粒与轻微磨损，与海报是同一层印刷。

**节奏式（脚印消散图）：**

> 沿着脚印延伸方向的延长线上有一行英文短句"further than home"，字母从靠近脚印一端的饱和主墨色（Ink）逐渐变淡、断笔，最后几个字母散成稀疏的网点，与脚印的网点消散共用同一方向、同一密度梯度——文字是这次消散的延续，不是标注。

**呼应式（裂痕图）：**

> 在裂痕蔓延方向的延长线尽头，有一句极小的手写铅笔字"它先裂开的地方最亮"，线条微颤，墨色为暖灰偏 Ink 方向，其中"亮"字墨量略重，像写字的人停了一下。

## 质检清单（生成后）

- [ ] 画面包含文字了吗？（除非用户明确说不要，否则没字就是失败生成）
- [ ] 文字写对了吗？（内容、拼写、笔画——错了直接重生成，这是底线不是风格）
- [ ] 墨色浓度符合所选档位？有没有意外加粗？
- [ ] 字和画面是否共享同一层纸/墨/颗粒？（如果出现"贴上去的贴纸感"，不合格）
- [ ] 是否遵守了画面的物理逻辑（消散方向、光源、透视线）？
- [ ] "破"不超过一处？
- [ ] 文字视觉权重低于主体锚点？
- [ ] 没用新色相？
