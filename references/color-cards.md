# 色卡系统 / Color Cards

这套风格永远只用**三个颜色角色**，每套色卡只是把这三个角色的具体色值整体挪动，角色分工不变。不要在三层结构之外引入第四个颜色。

## 三层角色定义

| 角色 | 作用 | 使用规则 |
|---|---|---|
| **Ground（纸基色）** | 画面的留白底色，模拟旧纸/道林纸质感 | 永远是留白区域的颜色，占比最大；不能用纯白或冷白，要偏暖、略带米黄。**允许在小范围内动态浮动**（见下方"Ground 的动态范围"），但不作为情绪表达手段——浮动只用来模拟"同一批纸张的自然色差"，情绪表达仍优先交给 Ink 色相偏移（见"新增色卡时的规则"里的情绪表达优先级） |
| **Ink（主墨色）** | 唯一允许的大面积实色 | 决定整套系列的"身份色"；只能是压灰度的靛蓝，不能是数字纯蓝（如 #0000FF） |
| **Mist（雾层色）** | 表现远近层次/空气透视的中间色 | 只用在离视觉焦点更远的次要形状上（远山、虚化辅助形），不能大面积铺开，否则三层结构会崩成普通渐变 |
| **Accent（点缀色，可选，默认不启用）** | 唯一允许跳出蓝白色系的例外 | 见下方"专色点缀"规则，仅限极特殊场景使用 |

## 专色点缀（Accent）规则——唯一允许的色系例外

这是整套色彩纪律里唯一的豁免条款，条件卡得很死，不是"看着好看就能用"：

1. **只能用于真实的光源语义**：窗光、烛光、灯笼、火光、远处一盏灯——本质上是"这里有光/有生命迹象"的暖色点，不能用于物体本身的固有色（比如一朵花、一件衣服不能借这条规则变红变黄）
2. **默认只能有一个实例**，除非满足第 4 条"分布式点缀"的全部条件——多个不相关的暖色点会把"专色点睛"变成"多色画面"，性质就变了
3. **面积必须落在"静态陈列型"的锚点上限内**（不超过画面 5%，见 halftone-spec.md），本质上 Accent 只能是"点"，不能扩展成"一片"（分布式点缀的多个实例合计也不能超过这个上限，见第 4 条）
4. **单一光源多实例（分布式点缀）——第 2 条的唯一例外**：如果多个暖色点属于同一因果链上的重复元素（比如一串顺流而下的河灯、一排依次点亮的灯笼），可以视为"一个点缀事件"而非多次独立例外，前提是必须同时满足：
   - 数量：3-5 个为宜，不超过 5 个
   - 因果关系明确：必须是同一物理过程的重复（同一批河灯、同一条街的路灯），不能是任意挑出的多个不相关光源
   - 强制的远近衰减：离视觉焦点最近的一个保持完整清晰，其余按远近顺序用网点密度递减，最远一个几乎融入 Ground——如果没有这种衰减梯度，只是简单排列的多个同样清晰的点，就不算"一个点缀事件"，算违规
   - 总面积仍然卡在静态陈列型的面积上限内（所有点缀加起来不超过 5%）
5. **必须是用户明确要表达"光/温暖/生命感"时才启用**，不是默认行为——常规意象（山、海、云、脚印）不需要也不应该引入 Accent
6. **色值建议**：暖金色 `#D9A85C` 附近，偏温暖但不刺眼，不要用高饱和的橙色或纯黄色，要和整体做旧纸感质感统一

违反第 1、2（在不满足第 4 条例外的前提下）、3 条中任意一条，就不算专色点缀，算色系失控，需要重新生成。

## Ground 的动态范围

Ground 不再要求锁死成单一精确色值，而是给一个窄区间，在区间内可以按具体生成情况微调（比如同一色卡多次生成时避免像素级重复），但区间要窄到肉眼几乎察觉不出差异——目标是"同一批纸的自然色差"，不是"不同的纸"。

**浅色系列（深海藏青版、雾山晨蓝版）共用同一个 Ground 区间**，不再各自定义独立色值，这样两套色卡背景天然统一，才配得上"同一套系列"的说法：

- 色相（Hue）：38°–42°
- 饱和度（Saturation）：32%–42%
- 明度（Lightness）：87%–91%
- 参考锚点值：`#F0E7D9`（区间中心，没有特殊理由时优先用这个）

**墨夜留白版（反转款）的 Ground 单独定义**，不与浅色系列共享区间，因为它是有意的"底片"效果：

- 色相：215°–225°
- 饱和度：45%–55%
- 明度：16%–20%
- 参考锚点值：`#16294A`

## 三套预设色卡

### 1. 深海藏青版 Deep Indigo

米白打底，深靛蓝做主体色块。适合：白天、辽阔、清晨、平静水面/天空类意象。

| 角色 | 色值 |
|---|---|
| Ground | `#F0E7D9`（区间见上，允许小范围浮动） |
| Ink | `#1E3F73` |
| Mist | `#A9BFDA` |

### 2. 雾山晨蓝版 Misty Mountain

三层次都启用，层次感最强，适合有远近关系的意象（山脉、云雾、层叠地形）。

| 角色 | 色值 |
|---|---|
| Ground | `#F0E7D9`（区间见上，与深海藏青版共用同一区间） |
| Ink | `#20447A` |
| Mist | `#8FA8C4` |

### 3. 墨夜留白版 Ink Night（反转版）

Ground 与 Ink 角色对调：深藏青做底，米白做主体。适合深夜、内敛、强反差的意象。

| 角色 | 色值 |
|---|---|
| Ground（此时为深底） | `#16294A` |
| Ink（此时为米白主体） | `#EDE4D0` |
| Mist | `#5A7BA8` |

## 选卡建议

| 意象关键词 | 推荐色卡 |
|---|---|
| 海、天空、清晨、辽阔、平静 | 深海藏青版 |
| 山、云、雾、远近层叠、地形 | 雾山晨蓝版 |
| 深夜、孤独、内敛、强对比 | 墨夜留白版 |

不确定时优先推荐深海藏青版（三套里最基础、最通用），并说明可以随时换卡。

## 新增色卡时的规则

如果要扩展新的色卡，必须：
1. 保持三层角色结构不变（Ground / Ink / Mist）
2. **Ink 色相硬性限定在 HSL 色相 200°-250° 区间内**（靛蓝到深藏青），不能出圈到偏绿的青色或偏紫的紫罗兰——情绪差异靠这个区间内的色相偏移 + 明度对比 + 网点密度/构图类型表达，不靠引入新色相
3. 给出和现有三套一样的"适用意象关键词"，方便后续自动推荐
4. **色卡总数建议不超过 4-5 套**。色卡越多，"每种情绪配一个新颜色"的偷懒风险越大，会稀释系列感——情绪表达应优先靠网点密度和构图类型（见 SKILL.md 与 halftone-spec.md），颜色只是最后的微调手段

### 情绪表达的优先级（颜色不是第一选择）

1. **构图类型**（横向地平线型 / 静态陈列型 / 扩散消散型）—— 影响最大，比换颜色更能定基调
2. **明度对比**（Ground 与 Ink 反差大→戏剧化/孤独；反差小→朦胧/温柔）
3. **网点密度与过渡节奏**（密而急促 vs 疏而缓慢）
4. **Ink 色相在 200°-250° 区间内的偏移**（偏 200° 更清透，偏 250° 更沉郁）——影响最小，放在最后调
